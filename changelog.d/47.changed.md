`JsonAgent` takes `tokens=TokenPaths(input=..., output=...)` instead of a tuple, and `input` must include the tokens read from and written to the cache, so an agent behind Anthropic counts more input than in older runs. A token count the agent does not give, `Usage.thinking` and the cache counts included, is now `NotReported()` instead of 0; runs are written in format 6, and runs of format 5 can no longer be resumed.
